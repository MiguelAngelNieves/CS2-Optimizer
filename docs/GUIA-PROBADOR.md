# Guía rápida para probadores

Gracias por probar CS2 Optimizer. Toma unos 40 minutos.

## Antes
- Instala [HWiNFO64](https://www.hwinfo.com/download/) (gratis).
- Abre CS2 una vez si nunca lo has abierto en este PC.

## Pasos
1. Descomprime el ZIP y abre **`Iniciar.bat`** (acepta el permiso de administrador).
2. **Escaneo**: revisa que tu CPU, GPU y RAM salgan bien.
3. **Prueba 0 (como lo tienes hoy)**, todavía sin aplicar nada:
   - HWiNFO64 → *Sensores* → botón verde **“+”** → guarda `prueba0.csv`.
   - Juega 10 min (casual o deathmatch, siempre el mismo modo).
   - Detén el registro → pestaña **Medir y comparar** → **Analizar CSV** → nombre: `original`.
4. **Usar recomendación** → cierra CS2 **y Steam** → **APLICAR**.
5. **Prueba 1**: repite el paso 3 con el nombre `recomendado`.
6. **Exportar diagnóstico** → envía el `.zip` que aparece en tu Escritorio.

## Cuéntanos también
- ¿Detectó bien tu equipo?
- ¿Se ve bien la resolución elegida?
- ¿Algún error en el cuadro de registro (abajo)? Una captura ayuda mucho.

Si algo no te gusta: **Ajustes → Restaurar todo** deja todo como estaba.
